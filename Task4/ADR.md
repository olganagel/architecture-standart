### <a name="_3bfxc9a45514"></a>**Функциональные требования**

|1|АБС|Экспорт ставок в файл|Обновление файла со ставками для внешнего колл-центра|

|3|Внешний колл-центр|Загрузка файла со ставками|Получение файла с SFTP и обновление БД|

|5|Оператор колл-центра|Просмотр ставок в интерфейсе|Отображение ставок в CRM-системе|

### **Нефункциональные требования**
|**№**|**Требование**|
| :-: | :- |
|1|Шифрование файлов|
|2|Доступность SFTP-сервера — 99.9%|
|3|Обновление ставок в файле — ежедневно|
|4|Задержка API колл-центра не более 500 мс|
|5|Совместимость формата файла - CSV|

### **Решение**
Диаграммы вложены в папку Task4

#### Основные компоненты:
1. АБС:
* Модуль экспорта ставок в файл
* REST API для внутреннего колл-центра
2. SFTP-сервер:
* Настроенный доступ для партнера
* Автоматическая очистка старых файлов
3. Колл-центр:
* Интеграция внутреннего АБС
* Парсер файлов для внешнего колл-центра

#### Выбор технологий:
SFTP из-за ограничений партнера
CSV как универсальный формат

### **Альтернативы**

|**№**|**Вариант**|**Преимущества**|**Недостатки**|
| :-: | :- | :- | :- |
|1|Прямое API для партнера|Мгновенное обновление ставок|Нужны доработки CRM партнера|
|2|Облачное хранилище|Масштабируемость|Затраты на лицензии|
|3|Веб-портал для партнера|Нет передачи файлов|Риски недоступности|

**Недостатки, ограничения, риски**
1. Задержки в обновлении файлов (до суток)
2. Ошибки парсинга файлов внешним колл-центром

**Меры по снижению рисков:**
1. Мониторинг логов
2. Тестовые файлы для проверки парсинга
3. Дополнительный SFTP-сервер
