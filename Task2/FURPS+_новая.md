| Код | Требования                         | Комментарий                                                                                   |
|-----|------------------------------------|-----------------------------------------------------------------------------------------------|
| F   | Функциональные (Functionality)     |                                                                                               |
| F1  | Клиент может подать заявку на депозит через сайт (ФИО + телефон) | Данные передаются в кол-центр для обработки                     |
| F2  | Клиент может подать заявку на депозит в интернет-банке (выбор счёта, суммы, подтверждение SMS) | Требуется интеграция с СМС-шлюзом |
| F3  | Автоматический расчёт ставок для клиентов интернет-банка на основе данных АБС | Уходит от ручного Excel-расчёта                    |
| F4  | Персонализированные ставки для клиентов интернет-банка | Учитывается история операций клиента                                      |
| F5  | Менеджер кол-центра видит заявки с сайта и может предложить особые условия | Интеграция сайта -> кол-центр -> АБС                  |
| F6  | СМС-уведомления клиенту после подтверждения ставки и открытия депозита | Используется текущий СМС-шлюз                             |
| F7  | Шифрование передаваемых данных (сайт -> кол-центр, интернет-банк -> АБС) | TLS 1.2+, PGP для чувствительных данных                 |
| F8  | Ведение ставок в АБС (вместо Excel) | Доступ для бэк-офиса депозитов и кредитов                                                    |
| U   | Удобство использования (Usability) |                                                                                               |
| U1  | Интерфейс соответствует корпоративному дизайну (цвета, шрифты, логотипы) | Единый стиль для всех каналов                           |
| U2  | Время отклика интерфейса < 500 мс | Оптимизация запросов к АБС, кэширование                                                        |
| U3  | Простота подачи заявки (максимум 3 шага) | Уменьшение числа полей для ввода                                                        |
| R   | Надёжность (Reliability)           |                                                                                               |
| R1  | Доступность интернет-банка и сайта — 99,9% (менее 9 часов простоя в год) | Развёртывание в двух ЦОД, балансировка нагрузки         |
| R2  | Автоматический failover при сбое в основном ЦОД | Переключение на резервный ЦОД за < 5 мин                                         |
| R3  | Защита от DDoS-атак и SQL-инъекций | WAF, параметризованные запросы                                                                |
| P   | Производительность (Performance)   |                                                                                               |
| P1  | Обработка заявки в интернет-банке < 1 сек | Оптимизация запросов к АБС, асинхронная обработка                                      |
| P2  | Поддержка 1000+ одновременных сессий | Горизонтальное масштабирование интернет-банка                                               |
| P3  | АБС должна выдерживать нагрузку от новых онлайн-заявок | Вертикальное масштабирование серверов БД Oracle                           |
| S   | Поддерживаемость (Supportability)  |                                                                                               |
| S1  | Совместимость с текущими технологиями (MS SQL, Oracle, .NET, Java) | Минимизация новых стеков                                      |
| S2  | Документация API для интеграции (OpenAPI/Swagger) | Для будущего расширения функционала                                            |
| S3  | Логирование всех операций (заявки, ошибки, SMS) | Аудит и расследование инцидентов                                                 |
| +R  | + Ограничения (Restrictions)       |                                                                                               |
| R1  | Запрет прямого доступа интернет-банка к API АБС | Использовать промежуточный слой (Kafka, REST-прокси)                             |
| R2  | Невозможность отказа от SMS-подтверждения | Требование ЦБ РФ для операций                                                          |
| R3  | Личная идентификация клиента в отделении для новых клиентов | Закон о противодействии отмыванию денег                              |
| R4  | Отсутствие Kafka в текущей версии интернет-банка | Альтернатива — RabbitMQ или REST-очереди                                        |
