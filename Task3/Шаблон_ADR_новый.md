### <a name="_3bfxc9a45514"></a>**Функциональные требования**
|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
|1|Клиент|Подача заявки на сайте|Клиент оставляет ФИО и телефон. Заявка передается в колл-центр|
|2|Клиент|Подача заявки через интернет-банк|Клиент выбирает счет и сумму, затем подтверждает смс, заявка отправляется в АБС|
|3|Колл-центр|Обработка заявки с сайта|Менеджер колл-центра получает заявку и на звонке с клиентом согласовывает условия|
|4|Бэк-офис(АБС)|Подтверждение заявки|Менеджер бэк-офиса верифицирует заявку и фиксирует ставку в АБС|
|5|Смс-шлюз|Нотификация|Клиент получает смс о подтверждении заявки или открытии депозита|

### **Нефункциональные требования**
|**№**|**Требование**|
| :-: | :- |
|1|Шифрование данных - TLS|
|2|Доступность интернет-банка — 99.9%|
|3|Время обработки заявки на сайте и интернет-банке - не более 1 секунды|
|4|Совместимость с текущими технологиями (MS SQL, Oracle, .NET)|
|5|Запрет прямых вызовов API АБС из интернет-банка (использование промежуточного слоя)|


### **Решение**
Диаграммы вложены в папку Task3

#### Основные компоненты:
1. Интернет-банк (ASP.NET, PostgreSQL):
* FE: Форма подачи заявки
* BE: Интеграция c асинхронной обработкой
2. Интеграционный слой (RabbitMQ):
* Очередь для снижения нагрузки на АБС
* Кэширование ставок для обеспечения высокой скорости ответа
3. АБС (Delphi, Oracle):
* Модуль расчета ставок 
* Логирование операций для аудита

#### Выбор технологий:
* RabbitMQ на замену несовместимой с интернет-банком Kafka
* REST API для безопасной передачи данных без прямого доступа к АБС
* Кэширование во избежание отказа  АБС
* Поддержка легаси (Delphi, ASP.NET)

### **Альтернативы**
|**№**|**Вариант**|**Преимущества**|**Недостатки**|
| :-: | :- | :- | :- |
|1|Интеграция с АБС без брокера|Простота реализации|Риск перегрузки АБС|
|2|Kafka|Масштабируемость, отказоустойчивость|Нужна миграция интернет-банка|
|3|Веб-сервисы на Java (вместо ASP.NET)|Лучше поддержка микросервисов|Отсутствие экспертизы в команде|

**Недостатки, ограничения, риски**
1. Задержки при обработке очередей брокера
2. Ограниченность в масштабируемости АБС

**Меры по снижению рисков:**
1. Мониторинг очередей
2. Резервные мощности для АБС
